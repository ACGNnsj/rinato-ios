# Rinato Mac chain runbook (grounded, untested here)

Chain model (upstream AGENTS.md + dmsh_chain.py + test_mac_metal.py):
1. After changing a chain tool: run dmsh_chain.py --header, commit dm/gfx/nvn/dmsh_chain.h (test_nsp_chain fails on stale).
2. Rebuild profile shaders: python dm/gfx/tools/dmsh_build.py <dm_dir> <out> [want...] (Mac and, with IOSOUT, iOS). Per-game out dir. Metal flags are pinned by test_mac_metal (xcrun -sdk macosx metal -c -O1, deployment target from dm/mac/min_os.mk, preserve-invariance/wrapv/relaxed-math).
3. Build stamps b-<V>/inputs.tsv (V = 12-digit tool-source sha); writes c1_full.tsv + cb_extent.tsv from Mac outputs; host takes them only beside the matching stamp. Then rebuild the host.

## CI-proven on GitHub runners (macos-shaders.yml, run 45748669483 green)

- Runner must be `xcode-27` with `DEVELOPER_DIR=/Applications/Xcode_27.2.app/Contents/Developer` plus `xcodebuild -downloadComponent MetalToolchain`; `macos-15` image ships metal 32023.620 but the lock wants 32023.922. Verify with `own_compilers.py --check-metal` before building.
- Copy the game profile into the clone (`dm/games/rinato-profile`): both `patch_nso` and `dmsh_chain.load_game()` read it from there, not from `DM_GAMES_DIR`.
- Komma-separated `shader_split.py` args are `(roms, mains, pkg-dir, map, facts, pairs, pso-pairs)`: the third arg is the shader **package directory** (receives `cs/ps/vs_main.bin`), NOT a label. `dmsh_build.py` takes that package dir as `<Switch package dir>`, not the tables dir.
- Main-only split (empty RomFS dir) yields a real subset: 11 shaders (V3/P7/C1), `cs/ps/vs_main.bin` packages, 14-line map / 2-line facts. Full 786-shader set needs the encrypted-RomFS decision.
- `dmsh_build.py` result on the subset: `shaders 11: ok 11`, Metal cache mac 11 compiled, side/pull libraries generated, 0 failures. Mac image `b-3b559c4b8d80.img` 476KB; with `IOSOUT` the same run reuses the mac cache and compiles ios 11, iOS image 370KB.
- iOS host needs no game files either (`macos-ios-build.yml`, run 45749983249 green): `compile_check.py` compiles every host source for the iPhone SDK, and `build_smoke.py` links the production `DmIOS.app` (Release-iphoneos) with synthetic modules. Required one profile addition: `app_category public.app-category.adventure-games` (otome adventure). Workflow step names must not contain an unquoted `: ` (YAML plain-scalar colon breaks registration: 0 jobs, 0s failure, run not retryable).
