# Rinato Mac chain runbook (grounded, untested here)

Chain model (upstream AGENTS.md + dmsh_chain.py + test_mac_metal.py):
1. After changing a chain tool: run dmsh_chain.py --header, commit dm/gfx/nvn/dmsh_chain.h (test_nsp_chain fails on stale).
2. Rebuild profile shaders: python dm/gfx/tools/dmsh_build.py <dm_dir> <out> [want...] (Mac and, with IOSOUT, iOS). Per-game out dir. Metal flags are pinned by test_mac_metal (xcrun -sdk macosx metal -c -O1, deployment target from dm/mac/min_os.mk, preserve-invariance/wrapv/relaxed-math).
3. Build stamps b-<V>/inputs.tsv (V = 12-digit tool-source sha); writes c1_full.tsv + cb_extent.tsv from Mac outputs; host takes them only beside the matching stamp. Then rebuild the host.
